💰 APP-Sales

销售数据抓取与报表：三源 → pos.db → 生意指标.xlsx，Mac mini 唯一总数据中心

📦 安装位置（Mac mini）

  • ~/APP-Sales/fetcher/ —— 抓取脚本（含 app-sales-fetch.py 主入口）
  • ~/APP-Sales/venv/ —— Python 虚拟环境（含 openpyxl）
  • ~/APP-Sales/数据文件/pos.db —— 订单明细库（SQLite）
  • ~/APP-Sales/数据文件/生意指标.xlsx —— 每日营收报表

🔑 用的权限和密码

名称存哪从哪来
SumUp API Key~/.sumup_api_key（600 权限）从 MacBook Air 同路径拷过来；源头是 SumUp 商户后台
Gmail 应用专用密码Mac 钥匙串（服务名 APP-Sales）https://myaccount.google.com/apppasswords 生成；ePassi / Edenred 邮件靠它读

⏰ 自动抓取（已启用）

  • 任务名：com.umami.appsales.daily-fetch
  • 位置：~/Library/LaunchAgents/com.umami.appsales.daily-fetch.plist（macOS 规定只能放这里，设置里看不到）
  • 时间：每天 15:30 自动跑
  • 跑什么：venv/bin/python fetcher/app-sales-fetch.py —— 抓 SumUp + ePassi + Edenred → 写 pos.db → 算利润 → 填生意指标.xlsx
  • 安装/重建：cd ~/APP-Sales/fetcher && bash setup_launchd.sh
  • 卸载：launchctl unload ~/Library/LaunchAgents/com.umami.appsales.daily-fetch.plist

查看方法（终端）

launchctl list | grep appsales          # 任务在不在
tail -20 ~/APP-Sales/fetcher/app-sales-fetch.log   # 跑没跑、报错没

🖐️ 手动抓取

  • 终端：~/APP-Sales/venv/bin/python ~/APP-Sales/fetcher/app-sales-fetch.py
  • 或点 APP-Kitchen 看板上的"Fetch & save"按钮（后台调同一个脚本）

📝 备注

  • 生意指标.xlsx 只记每日营收不记客数；购物券年底统一结算、不计入；利润=已扣工资的净利润
  • 换电脑时把整个 APP-Sales 文件夹拷过去，重建 venv（python3 -m venv venv && venv/bin/pip install openpyxl），再跑 setup_launchd.sh 即可
