🍳 APP-Kitchen

厨房订单看板：SumUp + ePassi + Edenred 三源汇入，实时显示当日订单

📦 安装位置（Mac mini）

  • ~/Documents/APP-Kitchen/APP-Kitchen.app —— 主程序，双击打开
  • ~/Documents/APP-Kitchen/kitchen.py —— 后端脚本（Python 标准库，无第三方依赖）
  • ~/Documents/APP-Kitchen/kitchen.db —— 本地订单库（SQLite）

🔑 用的权限和密码

名称存哪从哪来
SumUp API Key~/.sumup_api_key从 MacBook Air 同路径拷过来；源头是 SumUp 商户后台 API Keys 页
Gmail 应用专用密码Mac 钥匙串（服务名 APP-Sales，account=gmail_user / gmail_apppw）https://myaccount.google.com/apppasswords 生成 16 位；首次运行需本机点"允许"钥匙串访问

数据源头是 SumUp API + Gmail（云端权威），本地 db 只是缓存，任何设备拿 key 都能重抓。

📱 各设备分工与用法

设备干什么怎么用
Mac mini（家里，24h）总数据中心：跑看板 + 存 kitchen.db；也是 APP-Sales 的家双击 APP-Kitchen.app 打开；iPad 随航投屏可看
鸿蒙平板（店里厨房）纯显示端：看当日订单，有 done 按钮（状态只在内存，每天自动清零，不存盘）装 app-kitchen-signed.apk，打开即用，自己从 SumUp/Gmail 拉数据
iPad显示器：随航投屏看 Mac mini 上的看板Sidecar 连 Mac mini 即可（Tauri 不支持 iOS，无原生 App）
MacBook Air退役备份：原件保留，不再跑业务不用动

⚙️ 工作原理

  • 每 10 秒轮询 SumUp API，每 30 秒轮询 Gmail（ePassi / Edenred 邮件）
  • 订单状态两态：waiting → done（双击卡片流转）
  • 只显示芬兰时区当日订单，跨天自动消失（库中数据保留）
  • 看板上"Fetch & save"按钮会调 APP-Sales 的报表脚本（写 pos.db 与生意指标.xlsx，不回写看板）
  • 零端口设计：不开放任何网络端口

📋 备选方案：iPad 独立网页看板 备选

地址：/kitchen-board/ —— iPad Safari 直接打开，不依赖 Mac mini、不开端口、不走随航。

⚠️ 已知缺陷（2026-10-18）

  • 只显示 SumUp 订单，不含 ePassi / Edenred——浏览器 JS 调不了 Gmail IMAP（技术硬限制），ePassi 邮件订单看不到
  • API Key 需手动输入——存浏览器 localStorage，换浏览器/清数据要重输；Key 在 Mac mini ~/.sumup_api_key
  • 完成/恢复状态只在页面内存——刷新页面即丢失，不与 Mac mini 的 kitchen.db 同步
  • 依赖 SumUp API——API 故障或网络断开则无数据；每 30 秒自动刷新
  • 菜品名解析简化——直接用 SumUp product_summary，没有 kitchen.py 的完整菜名识别规则（Rest/Rest2 映射、收据补全等）

适用场景

  • Sonja 一人上班时用自己手机看单（不用给个人设备、不用给 API Key 的替代方案是鸿蒙平板 APK）
  • Mac mini 故障时的临时顶替（仅 SumUp 部分）
