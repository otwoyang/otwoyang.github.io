📄 eTasku 收据上传

两种上传方式：浏览器直接传 / 浏览器被禁时的邮件备用方案

方案1：浏览器直接上传 常规

  1. 登录 https://etasku.fi/login/（公司 Guaimost，用户 Qi Yang）
  2. 点左上角 RECEIPT 按钮（不是 documents）
  3. 点 New receipt，点 Add a File 选文件上传
  4. 填写三样：日期、金额、供应商名字（分类不重要）
  5. 保存，收据自动转给会计
⚠️ 上传只保证三样对——日期、金额、供应商名字。税率等字段能选就选，不能选空着，会计处理。

方案2：邮件发送到 eTasku 备用

当浏览器被管理员策略禁止访问本地文件（点 "Add a File" 没反应，提示 "Access to local files on your machine is disabled by your administrator"）时用此方案。

步骤

  1. 发件邮箱必须是 eTasku 注册邮箱（guaimost@gmail.com），eTasku 靠发件地址识别身份
  2. 收件人：oma@etasku.fi
  3. 附件：jpg 或 pdf 格式的收据
  4. 邮件主题会成为收据标题
  5. 邮件发出后，AI 进 eTasku 浏览器找到那条新收据，把日期、金额、供应商等数据改对填全（上传文件被禁，但改数据没被禁）

注意

  • 收据日期记为发邮件当天，不是小票上的日期，事后要手动改回正确日期
  • eTasku 用 OCR 读附件，金额可能读不出来，要去核对补全
  • 已实测可用（2026-10-18）
