🎨 我喜欢的风格设计

Life / Digital / Style —— 以后设计的网站都要参考这个方案（2026-11-02 用户亲口定）

定版

一句话定义：图标网格的布局，像素图标、像素字体，选中的地方整块变绿。布局用大图标网格，风格用 RetroArch RGUI 的绿框、棋盘格黑底和像素字体。以后做任何界面，先拿这张图对照。

定版标准样图：顶部绿字标题 MAIN MENU，4 列 × 3 行共 12 个像素图标（WEB BROWSER、FILE MANAGER、TERMINAL、MEDIA PLAYER、RETRO GAMES、CODE EDITOR、PYTHON、GPIO TOOLS、SYSTEM SETTINGS、VNC SERVER、ARDUINO、PI MONITOR），选中的 WEB BROWSER 整块变绿，底部 HOME / APPS / SETTINGS 三页签，当前页签 APPS 变绿。

本页就是完整版，不依赖 PDF。改本方案里的任何数值，先改本页，再改实现，不许只改实现不改文档。

风格构成：四件事，缺一不可

构成是什么为什么
黑底棋盘格纯黑打底，上面铺一层深灰棋盘格纹这是 RGUI 的底子，也是复古游戏机的味道；格纹让大片黑不空、不闷
亮绿粗框整个界面一圈粗绿框，分区也用绿线荧光绿是这套风格的签名，一眼认得出；粗框才有像素味，细线没有
像素图标图标必须是像素画法：方块颗粒、硬边、无渐变入口靠图标认，不靠文字找；像素颗粒和字体、边框是同一家人
像素字体英文全大写像素字，标题、标签、页签都用它字本身就是装饰；换成圆润的现代字体，整个风格立刻散掉

它不是什么

  • 不是现代扁平风：没有圆角卡片、没有柔和阴影、没有渐变色块
  • 不是彩色活泼风：除了绿、黑、白，不许再引入装饰色
  • 不是纯文字列表：RGUI 的列表只作风格来源，正式界面永远用图标网格做入口
  • 不是照片风：界面里不放写实照片当背景，图就是像素图标本身

风格来源：RetroArch 的 RGUI 菜单（绿字黑底、棋盘格、绿框、选中行变绿带 > 标记）。本方案只取它的颜色、边框和像素字，布局不用它的文字列表，改用图标网格。

配比与规矩

  • 配比：黑约 70%，白约 20%，绿约 10%。绿是点睛，不能大面积铺；大面积绿只有一种情况：选中项整块填选中绿
  • 选中 = 整块变绿：字和图标变签名绿或纯黑，不许只描个边了事
  • 功能色例外，仅用于状态：报错红 #FF5147、提醒黄 #FFC400。只出现在提示和状态点上，永远不做装饰、不做标题、不做边框
  • 禁止：任何渐变、任何半透明彩色、任何绿以外的装饰色、灰阶以外的中性色（暖灰、米色都不行）
  • 对比：白字和绿字只放在黑底上；绿底（#248C22）上只放黑字或白字，不放亮绿字

文字规范：像素字当家

用途字体规矩
英文 / 数字标题与标签像素字体（Press Start 2P 一类方块像素字）全大写；字距 1–2px；只用于标题、标签、页签、按钮
中文标题粗体黑体（Noto Sans SC Bold / 思源黑体粗体）字距 2px；与英文像素字同行时以像素字高度对齐
中文正文常规黑体（Noto Sans SC Regular）不用像素字排长中文（笔画会糊），正文求清楚
数字 / 编号 / 代码等宽字体（JetBrains Mono / Noto Sans Mono）序号、时间、参数一律等宽，方便对齐扫读

网格布局（照定版图）

  • 入口区：桌面 4 列，行数按入口数走；首页核心入口 12 个 = 4 列 × 3 行，和定版图一致
  • 小屏：手机竖屏改 3 列，更小的屏改 2 列；列数变，图标和字不缩
  • 底部页签：固定 3 个等宽页签（或按实际栏目等分），高度 56–64 px，永远贴底
  • 顺序：最常用的排左上第一位；选中态出现时网格不跳位、不重排

落地规则：以后都照这份做

网站怎么套

  • 整站底子：黑棋盘格背景 + 绿外框是站点的脸，任何页面不得换底色、不得去掉格纹
  • 首页：照定版图 —— 顶部标题、图标网格入口、底部页签，三段式不变
  • 内页：标题带 > 标记，内容分区用 2px 绿线，长内容用菜单列表组件组织
  • 图片：站内图优先像素风插图；必须用照片时，照片加 3px 绿框，当作“贴纸”贴在黑底上，不许照片铺满当背景
  • 小屏设备界面（如中屏启动器）：同一套数值等比缩小，外框 4px、图标 64px，规矩一条不少

禁忌清单（出现一条就是跑偏）

  • 圆角大于 2px、卡片柔和阴影、毛玻璃效果 —— 全禁
  • 蓝、紫、粉、橙等装饰色，任何渐变色 —— 全禁
  • 圆润的现代线性图标、表情包式彩色图标 —— 全禁，图标必须像素画法
  • 正文用宋体、楷体等衬线体，英文标签写小写 —— 全禁
  • 选中态只改字色不填底、或用下划线表示选中 —— 全禁，必须整块变绿

验收清单（交付前逐项打勾）

  • □ 背景是黑棋盘格，格子大小 24px（大屏 32px），全站一致

  • □ 颜色只有绿、黑、白、灰，功能红黄只出现在状态提示

  • □ 选中项整块填 #248C22，和定版图的 WEB BROWSER 一样
