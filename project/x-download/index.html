🐦 X 视频下载

发链接给 Muse，自动下载到 Mac mini

📋 流程

  • 用户发 x.com 视频链接到聊天
  • Muse SSH 上 Mac mini，用 yt-dlp 下载
  • 存到 ~/Documents/x.com/
  • 文件名：YYYYMMDD_账号_推文ID.mp4（日期取下载当天）

🔧 技术细节

  • 工具：yt-dlp（Mac mini 上 /Users/otwoyang/Library/Python/3.9/bin/yt-dlp）
  • 登录态：--cookies-from-browser safari（Mac mini 的 Safari 必须已登录 X）
  • 为什么需要登录：X 把免登录视频接口掐了，成人/限制内容必须登录才能下
yt-dlp --cookies-from-browser safari --no-playlist \
  -f "best[ext=mp4]/best" \
  -o "20261018_账号_推文ID.%(ext)s" \
  "https://x.com/账号/status/推文ID"

⚠️ 注意

  • 三类链接：带 /video/1 直接下；不带先 --list-formats 探测；被识别成 playlist 加 --no-playlist
  • 完整性校验：ffprobe 看分辨率/时长 + ffmpeg 解码无报错
  • Mac mini 本地下载，无 120M 限制（那是 pCloud 的）
